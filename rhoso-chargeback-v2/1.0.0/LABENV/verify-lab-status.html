Verify Labe Environment Status

The OpenShift cluster provisioned in the lab environment may require up to an additional 30 minutes to become fully ready, even if its status is shown as Ready on the Red Hat Online Learning (ROLE) platform. Before proceeding with the lab, verify that the cluster is fully operational by following the instructions on this page.

  1. Check the overall cluster version and update status, and verify the health of all core cluster operators.

    oc get clusterversion
oc get clusteroperators

    Ensure AVAILABLE is True, PROGRESSING is False, and DEGRADED is False for all cluster operators.

  2. Check the status of all nodes and machine config pools.

    oc get nodes
oc get mcp

    Ensure all nodes are Ready, and machine config pools show UPDATED as True and DEGRADED as False.

  3. Check for pods across all namespaces that are not running or have not completed successfully.

    oc get pods -A | grep -v -e Running -e Completed

    Ensure the command returns no output. If pods are listed, investigate those in CrashLoopBackOff, Pending, or Error states.

  4. Check CPU and memory utilization across all nodes.

    oc adm top nodes

    Ensure no nodes are approaching their available CPU or memory capacity.

  5. Monitor the cluster version, machine config pools, and node status in real time.

    watch "oc get clusterversion; echo; oc get mcp; echo; oc get nodes"

    Use this command during cluster updates or troubleshooting to monitor changes in cluster health.

If any check indicates an unhealthy state, wait 30–40 minutes from the time the lab was provisioned for the OpenShift cluster to reach a fully ready state. If the cluster remains unhealthy after this period, investigate the affected cluster operator, node, pod, or machine config pool before proceeding with the lab.
