Welcome to this training on Red Hat OpenStack Services on OpenShift, or RHOSO, Chargeback and Observability Fundamentals. In this course, we will explore how to monitor and rate resource consumption within your cloud infrastructure. You’ll learn how the RHOSO Observability stack collects vital metrics and logs, and how the Rating service—powered by CloudKitty—transforms those raw technical metrics into meaningful cost data for your chargeback and showback reporting.

By the end of this session, you will be able to enable the Rating service within a RHOSO environment, create the necessary rating rules to assign costs to specific cloud resources, and successfully retrieve consumption data for financial reporting.

This course covers several key topics. We’ll begin with the basics of RHOSO Observability, covering the architecture and core functionalities for collecting and storing metrics and logs. Next, we’ll introduce the Rating service, where we will discuss the chargeback use case and how CloudKitty bridges the gap between technical operations and financial reporting. We will then walk through the steps to enable the Rating service in RHOSO using the Telemetry Operator. You’ll also learn how to configure the rating module, define your metrics, and manage your rules. Finally, you’ll complete a hands-on lab to implement your first chargeback rating, and we will conclude with a guide on basic rating troubleshooting to help you diagnose common issues.

You have two options for how to approach this training. If you prefer a guided path, I recommend following the modules in order. This builds a strong theoretical foundation before you start the practical work. Alternatively, if you prefer a "hands-on first" approach, you can jump directly to the lab. Each lab unit includes links back to the relevant theory modules, allowing you to refer to the documentation whenever you need more context. I also encourage you to keep the troubleshooting section as a reference; while it isn’t required to complete the course, it will be an invaluable resource when you encounter issues in the lab or in a production environment.

Before we begin, ensure you have the necessary prerequisites. This training assumes you have a basic familiarity with RHOSO architecture, a working knowledge of OpenShift and the `oc` command-line interface, experience with core OpenStack concepts like projects, flavors, and instances, and a basic understanding of how to use Ansible playbooks.
